# Galeria de Fotos 📸

Este projeto é uma réplica simplificada e estática da interface de grade do Instagram. O objetivo principal é consolidar conhecimentos práticos em **CSS Grid Layout** para a criação de grades responsivas e aplicar efeitos visuais interativos através de transições em CSS.

## ✨ Demonstração e Funcionalidades

O projeto simula a seção de publicações de um perfil de rede social, contendo:
* **Grade Responsiva:** Layout flexível que se adapta automaticamente ao tamanho da tela do usuário utilizando CSS Grid.
* **Efeito Hover Interativo:** Animação de zoom suave e sobreposição de camada escura (overlay) ao passar o ponteiro do mouse sobre as imagens.
* **Design Limpo:** Estilização minimalista focada na valorização do conteúdo visual.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e organização dos blocos de imagem.
* **CSS3:** Gerenciamento do layout com Grid, uso de pseudo-classes (`:hover`) e propriedades de transformação/transição visual.

## 📦 Como Rodar o Projeto

Para visualizar a galeria localmente na sua máquina:

1. Baixe ou clone os arquivos deste repositório.
2. Certifique-se de manter os arquivos `index.html` e `style.css` no mesmo diretório.
3. Abra o arquivo `index.html` em qualquer navegador web moderno.

## 🗂️ Estrutura de Arquivos

```text
├── index.html   # Estrutura e marcação das imagens da galeria
└── style.css    # Regras de Grid, responsividade e efeitos de animação
```
